A small language model writes an answer from the passages below, on this device: it downloads once (several hundred MB, then cached) and nothing leaves the browser.

    How it works: the passages were embedded once with bge-small-en-v1.5 and stored in Lance tables, sorted by IVF partition. Your question is embedded here with the same model (transformers.js); nanolance's WebAssembly reader then fetches only the nearest partitions' rows by HTTP Range from this static site.
